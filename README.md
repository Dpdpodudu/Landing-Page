# Landing Page - Modern Tech Website

This project is a responsive, interactive landing page designed for a modern technology and audio brand. It showcases a clean, minimalist user interface with detailed product category sections, an engaging layout, and full responsiveness to ensure a seamless browsing experience across desktop, tablet, and mobile devices.

Experience the live website: [Live Demo](https://dpdpodudu.github.io/Landing-Page/)

## 💻 Technologies Used

**Core:**
* **HTML5** – Semantic markup and page structure
* **SCSS** – Advanced styling, variables, and mixins
* **JavaScript** – Interactive elements and DOM manipulation

**Architecture & Tools:**
* **BEM Methodology** – (Block, Element, Modifier) for maintainable, scalable, and reusable CSS architecture
* **Gulp / Parcel** – Build tools and local development server
* **npm** – Package manager
* **GitHub Pages** – Hosting and deployment
